Catálogo de Server Actions

A camada de escrita do Torcida SaaS não é REST — são Server Actions do Next.js ("use server"). Cada card abaixo é uma ação de mutação: o gate de permissão que a protege, a validação de entrada, o que grava no banco e o rastro de auditoria.

Como ler o gate. assertPermission(X) é o único critério do admin (servidor, nunca no cliente). Ações do portal exigem só Sessão (usuário logado) e, quando restritas, assertMembroAtivo. Super-admin = e-mail na allowlist de ambiente.
Nenhuma ação corresponde ao filtro.
